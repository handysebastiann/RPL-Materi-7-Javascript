## Deskripsi Projek

Projek ini merupakan pengembangan dari website **My Daily Journal** berbasis HTML, Bootstrap 5, Bootstrap Icons, dan JavaScript sesuai penugasan pada materi **7 - JavaScript**.

## Penugasan

1. **Tanggal dan Jam (Slide 34)**
   - Menampilkan tanggal (`DD/MM/YYYY`) dan jam (`HH:MM:SS`) secara *real-time* pada bagian *Hero* menggunakan built-in object `Date` dan pembaruan tiap detik (`setInterval`).
2. **Scroll to Top (Slide 34)**
   - Tombol bulat berikon panah atas di pojok kanan bawah halaman yang otomatis muncul saat halaman digulir ke bawah (`window.scrollY > 300`) dan menggulir kembali ke atas saat diklik (`window.scrollTo`).
3. **Theme Switcher — Dark & Light Mode (Slide 35)**
   - Dua tombol berikon pada *navbar*:
     - **Dark** (`bi-moon-stars-fill`): mengubah warna *background* menjadi gelap dan warna teks menjadi terang menggunakan manipulasi DOM & CSS (`classList` dan `style`).
     - **Light** (`bi-brightness-high`): mengembalikan tampilan ke tema terang (*default theme*).
